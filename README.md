# 鲜时家 - 10年代复古风日期记忆保鲜网上商城

本系统是一个模拟 2010 年代电商视觉风格与交互逻辑的购物商城系统。基于极简的 `Python Flask` 后端和 `SQLite` 数据库开发。

---

## ✦ 系统核心亮点与设计特色

1. **复古凡客/淘宝风**：
   - 采用 10 年代经典的直角红底/橘底按钮（无圆角）。
   - 核心表格均采用粗实线框/双线框（`retro-table`）进行绘制，简单粗暴。
   - 网页两翼配置有随屏幕滚动的“新手指南”与“特惠大促”挂件，主体为 1200px 居中阴影布局。
   - 包含首尾相接、只向左方单向滑动的无缝循环轮播图，以及经典的像素防滑暗纹背景。

2. **多档 SKU 与动态价格联动**：
   - 提供了 **日期记忆保鲜盒**（大号：12.90元 / 小号：9.90元）和 **日期记忆保鲜袋**（大号：7.70元 / 小号：5.50元）两款真实可购商品，支持大图及实物图相册自由切换预览。

3. **安全图形验证码系统**：
   - 注册及登录模块在框内动态加载由前端 Canvas 算法实时绘制的“扭曲噪点字符验证码”，不占用任何服务器运算成本。

4. **安全越权隔离与商家激活邀请码**：
   - 只有管理员角色的账户才能进入商家控制台。
   - 注册时输入专属的激活码才能成功激活商家角色（非必填，留空则为普通买家）。
   - **预设的管理员激活邀请码**：
     - `XianShiJia2026`
     - `AdminActiveCode`
     - `SchoolShowCase`
   - 管理后台支持手动输入快递运单号对已付款订单进行“手动发货”，同时支持对商品的库存、价格等进行实时修改，前台立刻同步生效。

5. **极其强劲的内存管理与连接安全**：
   - 采用 Flask 的 `teardown_appcontext` 机制注册 thread-local 级别的数据库连接池，请求销毁时 100% 自动安全释放 SQLite 连接，绝不泄露句柄。
   - 配置有热重载排除规律（`exclude_patterns`），写入 SQLite 数据库时不会错误地触发 Flask 服务频繁重启，彻底杜绝 Windows 开发环境下内存累积 OOM 致命隐患。

## ✦ 快速本地部署与启动

### 1. 环境准备

确保您的计算机上已安装 Python 3.6 或更高版本。

### 2. 初始化数据库 (SQLite)

在项目根目录下打开终端，执行以下命令，该命令会自动在根目录下创建 `database.db` 数据库文件，并插入商品、预设激活码、评价等初始数据：

```bash
python init_db.py
```

### 3. 启动 Flask 后端服务器

运行主应用启动脚本：

```bash
python app.py
```

终端会输出如下地址：

```text
 * Running on http://127.0.0.1:5000 (Press CTRL+C to quit)
```
